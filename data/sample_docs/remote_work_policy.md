# Remote Work and Security Guidelines

## Eligibility

Employees may work remotely up to three days per week with manager approval. Fully remote
arrangements require director-level sign-off and a documented business justification.

## Equipment

The company provides a laptop and monitor for remote work. Employees are responsible for a
reliable internet connection. Equipment must be returned upon termination.

## Security Requirements

All remote connections must use the company VPN. Multi-factor authentication is mandatory
for all systems. Confidential documents must never be stored on personal devices.

## Incident Reporting

Report any suspected security incident to the security team within one hour of discovery via
the incident portal or the emergency hotline.
